





❤️ Heart

Heart is an interactive, story-driven web experience built with React, TypeScript, and Vite. Instead of a traditional webpage, it guides the user through a cinematic sequence of animations, terminal-style interactions, decryption effects, and an animated heart that culminates in a heartfelt letter.

✨ Features

- 💻 Terminal-inspired boot sequence
- 🔐 Interactive authentication challenge
- 🔓 Animated decryption with glitch effects
- ❤️ Dynamic canvas-rendered heart animation
- 💌 Elegant final letter reveal
- 🎭 Easter egg hidden within the heart stage
- 📱 Responsive design for desktop and mobile
- ⚡ Built with React and Vite for fast performance

🛠️ Tech Stack

- React
- TypeScript
- Vite
- HTML5 Canvas API
- Modern CSS
- React Hooks

🚀 Getting Started

Clone the repository

git clone https://github.com/688-png/heart.git
cd heart

Install dependencies

npm install

Start the development server

npm run dev

Open your browser and visit the local address displayed by Vite (typically "http://localhost:5173").

📦 Build for Production

npm run build

Preview the production build locally:

npm run preview

🎬 Experience Flow

The application progresses through five interactive stages:

1. Boot – Simulates a secure system startup.
2. Authentication – A password terminal with humorous denial messages before an automatic override.
3. Decryption – Interactive message fragments reveal themselves with glitch animations.
4. Heart – A live animated heart rendered on an HTML canvas with a hidden easter egg.
5. Final Letter – A beautifully presented personal message.
